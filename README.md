# 轨道工坊 · Track Playground

可离线运行的 Godot 4 原生 3D 模型铁路模拟器，包含源代码、本机运行时、示例布局与可用的 Mod 数据包。

## 启动

双击 **TrackPlayground.exe**，或运行 `启动轨道工坊.cmd`。

无需安装编辑器或联网。请保留项目目录中的 `runtime/`、`scripts/`、`mods/`、`project.godot` 等文件。运行时为本机已有的 Godot 4.7.2，许可证和第三方声明位于 `runtime/`。需要 Windows 和支持 OpenGL 3.3 的显卡。

开发时可在 Godot 打开 `project.godot`，或运行 `./Start.ps1 -Editor`。缺少导入缓存时，EXE 启动器会自动执行首次导入。

## Web 与 Windows 导出

运行 `./Export.ps1` 将 Web 版输出到 `web-dist/index.html`；`./Export.ps1 -Target Windows` 将独立 Windows EXE 输出到 `build/windows/TrackPlayground.exe`；`-Target All` 同时生成两种版本。原有 `TrackPlayground.exe` 启动器和 `Start.ps1` 仍可使用。可加 `-DebugBuild` 导出调试版本。

导出需要与 `runtime/Godot.exe` 匹配的 Godot 4.7.2 官方模板。本工作区已放在 `export_templates/4.7.2.stable/`，新克隆需从官方 `Godot_v4.7.2-stable_export_templates.tpz` 解压其中的 `web_nothreads_{debug,release}.zip` 和 `windows_{debug,release}_x86_64.exe` 到该目录。模板和构建输出不提交到 Git。

在项目目录运行 `python -m http.server 8000 --bind 127.0.0.1`，再访问 `http://localhost:8000/web-dist/`。部署时将 `web-dist/` 中的文件完整上传至任意静态站点目录；HTML、脚本、WASM 和资源包均使用相对路径，支持子目录部署。请通过 HTTP/HTTPS 访问，不能直接双击 HTML 运行。服务器需正确提供 `.wasm` 的 `application/wasm` 类型；生产部署建议启用 gzip/Brotli 压缩。

Web 版使用 WebGL 2.0 与单线程导出，无需配置 COOP/COEP 响应头。中文字体、音效和示例 Mod 均随包提供。浏览器首次交互后才允许声音播放；复杂布局性能取决于浏览器和设备。

项目已启用 `addons/runtime_sources` 导出插件，为两个平台保留运行时直接读取的原始 WAV 和 Mod GLB；导出时请保持该插件启用。浏览器验收脚本为 `tools/test_web.cjs`，依赖和运行方式见文件开头，报告输出到 `test-results/web.json`。

- 点击顶部「打开」：选择本地 `.railway` 文件（仅在浏览器内读取，不上传服务器），或输入场景文件 URL。支持 `./layouts/example.railway` 等相对地址，按当前网页目录解析。
- 也可通过 `index.html?scene=./layouts/example.railway` 自动加载。完整外站地址应进行 URL 编码；外站需允许 CORS，HTTPS 页面应使用 HTTPS 场景地址。
- 点击「保存」下载当前 `.railway` 文件，与 Windows 版格式相同。Web 不直接访问本机路径；单个导入文件上限 32 MiB。
- 场景通过格式、零件和列车路径校验后才替换当前场景，加载后暂停，可撤销恢复。失败时保留当前布局。引用额外 Mod 的场景需要先将相应 Mod 放入项目再重新导出。

## 功能

- HO 1:87.1 / 16.5 mm 轨距，N 1:160 / 9 mm 轨距。每个场景使用一种比例。
- 直轨、弯轨、左右道岔，端点位置和方向吸附，旋转、镜像、高程、±8% 坡度。
- HO/N 柔性直轨、圆弧柔轨、S 形柔轨和缓和曲线，可调长度、半径、角度或横向偏移，支持镜像、坡度与起点/终点锚定。
- 两端点自动连接：悬浮预览，自动拟合位置、朝向和高差；检查最小半径、8% 坡度上限、自交与沙盘边界。
- 多列车独立调速、停车、急停、停车后换向、暂停、跟随视角。每编组最多 24 辆，可包含多个机车；最多 64 个编组。
- 原创合成音效：铺轨、端点连接、删除、道岔扳动、编组挂接、提示与保存反馈；柴油、电力、蒸汽机车运行声及轮轨声随车速变化，带空间方位与距离衰减，支持鸣笛和制动放气声。
- 编组车间连接：可转动的车钩、钩头锁销与下垂软管，相邻客车的折棚风挡，以及蒸汽机车—煤水车牵引杆；随弯道、坡度和脱轨姿态更新，支持 HO/N 与放置预览。
- SY 0808 蒸汽机车与独立煤水车：2-8-2 轴式、镂空辐条动轮、随路程联动的连杆与配汽机构、烟囱烟雾，以及锅炉管线、铆钉、车号、开放侧窗、驾驶室仪表和煤堆细节。HO/N 自动缩放。
- 其余车辆也采用精细模型：柴油机车的百叶格栅与带网罩风扇、电力机车的受电弓与绝缘子、客车的圆弧车顶与透窗座椅、集装箱的波纹板和箱门锁杆、罐车的弧形封头与爬梯平台，以及山地柴油机车的机罩和侧走道。均具备完整底盘、转向架、悬挂、制动细节及随行程滚动的轮组。
- 60 Hz 动力学：质量、功率、牵引力、干/湿轨黏着、运行阻力、逐车坡度、制动。显示原型等效 km/h 与模型实际 mm/s。
- 车辆碰撞物理：迎头、追尾、倒车撞击、道岔并轨、交叉侧撞及残骸连环碰撞；按逐车质量、接触位置和速度产生冲量、滑移、偏转及翻滚，保留车钩连接。支持切回接触停车模式。
- 轨道占用与道岔锁定、弯道超速与轨道尽头保护；关闭脱轨保护后支持尽头脱轨、重力坠落及地面碰撞。
- 窗口可自由调整比例，3D 画面铺满窗口；工具栏自动换行，两侧面板可滚动。
- 默认启动为空白沙盘；新建时可设置宽度、深度（各 0.5–10.0 米，步进 0.1 米），尺寸随场景保存并支持撤销/重做。
- 地形抬高、降低、整平、平滑、草地/砂土绘制；固定水位形成湖泊；一键整平线路路基。
- 树、房屋、车站、站台、山石及自定义 GLB 布景，随地表高度落位。
- `.railway` 场景保存/打开、30 步撤销/重做；载入与撤销后暂停模拟。
- JSON Mod API v1，自定义轨道尺寸、车辆尺寸/动力、车辆与布景 GLB 模型。附 `alpine_pack` 示例。

## 操作

| 操作 | 方法 |
| --- | --- |
| 旋转 / 平移 / 缩放视角 | 按住右键 / 中键 / 滚轮 |
| 暂停、继续模拟 | 空格或右上按钮 |
| 铺轨 | 「轨道」中选零件，点击沙盘；靠近开放端点自动吸附 |
| 旋转、镜像零件 | R / F；镜像弯轨与道岔可改变左右方向 |
| 切换铺轨端点 | Tab 切换跟随鼠标及吸附的端点；直轨、弯轨切换起点/终点，道岔循环入口/直股端/侧股端；圆点标示当前端点 |
| 铺设柔轨 | 「轨道」选择柔性直轨 / 圆弧柔轨 / S 形柔轨 / 缓和曲线柔轨，在面板上方调整参数后点击沙盘；蓝色虚影可放，红色虚影显示不可放原因 |
| 自动连接 | 「轨道 → 自动连接 · 选择两个端点」，依次点击两个金色开放端点；悬浮第二点显示曲线，左键完成；再次点击起点可重选，Esc 取消 |
| 切换道岔 | 「行车」模式点击道岔；黄色为直股，绿色为侧股；占用时锁定 |
| 创建列车 | 左侧按前后顺序添加车辆，点「将编组放上轨道」；悬浮轨道显示整列半透明虚影，蓝色可放置、红色不可放置；左键指定车头位置 |
| 切换放置方向 | 放置编组时按 Tab，以鼠标所在的车头位置翻转朝向；Esc 取消 |
| 控制列车 | 点击右侧编组名称或列车，拖动滑块设定速度；换向前停车 |
| 碰撞物理 | 「行车」面板的「车辆碰撞物理」默认开启，独立于「脱轨保护」；关闭后接触停车。撞击后的编组可暂停、保存或复位上轨 |
| 鸣笛 | 选中列车后按 H，或点右侧「鸣笛」；蒸汽机车使用汽笛 |
| 音量 / 静音 | 顶部「声音」，分别调整总音量、操作音效、列车声音；自动记住设置 |
| 修改已放置编组 | 停车后编辑草稿，点「用草稿替换选中编组」 |
| 编辑地形 | 选择笔刷，按住左键拖动；每次拖动可单独撤销 |
| 放置/删除布景 | 「布景」选择零件后左键放置；橡皮擦删除 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 保存 / 打开 | Ctrl+S / Ctrl+O |
| 取消工具 | Esc，回到行车模式 |

默认打开 **3.4 × 2.6 米的平整空白沙盘**，没有预放置的轨道、列车或布景。左侧「场景 → 新建空白沙盘」可分别填写宽度和深度，单位为沙盘实际米数；切换 HO/N 比例时保留尺寸并新建空白沙盘。旧存档仍按原来的 3.4 × 2.6 米读取。

「载入示例布局」可打开 3.4 × 2.6 米的双环线、两列运行列车，以及**与环线独立的道岔练习区**。建议先从 15–25 km/h 原型等效速度试车；模型铁路的较小弯道半径通常不适合原型高速。按住中键拖动时，沙盘画面跟随鼠标方向平移。

添加蒸汽机车：在「行车」的车辆下拉框选择 **SY 0808 · 蒸汽机车（含煤水车）**，点「＋ 添加到编组」，会依次加入机车和煤水车，占用两个车辆位置。需要单独编组时先点「清空」，再添加、放上轨道。煤水车作为独立车辆沿轨道转向，可单独移除或添加。模型以 SY 风格原创建模，尺寸与动力参数用于本模拟器，并非特定实车的测绘复刻；仍采用既有纵向动力学，不模拟烧煤、锅炉压力或燃料消耗。

铺轨高程独立于地形，适合制作坡道、填方与高架线路。地形变更后可以点击「整平全部轨道路基」；本版不自动生成桥墩或隧道。端点连接容差为 4 mm，并检查相对朝向。

音量设置独立保存在用户数据目录的 `audio.cfg`，不随场景载入、撤销或比例切换改变。暂停时停止运行声，可手动鸣笛；柴油机车停车时保留轻微怠速声。运行声优先播放距镜头最近的 8 个编组，避免大量列车叠加过响；混合编组使用蒸汽、柴油、电力的优先顺序选一种机车声，其他 Mod 机车默认使用柴油声。所有声音均为原创合成素材，无需联网；不是实车录音。

柔性直轨可调长度 10–2000 mm；圆弧柔轨可调半径 80–5000 mm 和转角 1–180°；S 形柔轨可调纵向跨度和横向偏移，两端保持平行；缓和曲线的曲率从零逐渐增加至指定末端半径。选中柔轨后，参数显示在左侧面板上方。所有柔轨均支持保存、载入、撤销、路基整平与列车运行，弯道保护按局部半径计算。

自动连接默认最小半径 180 mm，可在按钮下方调整。选中第一点后以金色圆点标记；第二点的蓝色虚影表示可连接，红色表示不满足限制。成功后生成一个柔轨零件，Ctrl+Z 可整体撤销；失败时保留起点并说明原因。支持直线、错位 S 弯、转弯、回转及不同高程端点，也可选道岔侧股端。求解采用平滑曲线尝试连接，不保证任意端点组合都有解，也不会绕开既有轨道、地形或布景；必要时调整端点位置、朝向或最小半径。

「行车 → 物理环境 → 启用脱轨保护」默认开启，弯道超速或到达轨道尽头时停车。取消勾选后，列车驶出尽头会保留惯性，由逐车刚体模拟下落、翻滚及落地。轨道有高程、下方地形较低时，可以观察高架坠落；不要将尽头下方的地形整平到轨道高度。右侧「复位 / 脱轨列车重新上轨」可在原轨道位置空闲时恢复编组。暂停、保存与载入也会保留脱轨车辆状态。

## 文件与开发

默认用户数据保存在项目内 `.runtime/Roaming/Godot/app_userdata/轨道工坊 · Track Playground/`。保存对话框也可选择其他目录。数据包放入 `mods/` 后重启生效。

- [Mod 接口](docs/MOD_API.md)
- [物理模型与边界](docs/PHYSICS.md)
- `scripts/rail_graph.gd`：轨道拓扑；`simulation.gd`：路线与动力学；`terrain.gd`：地形；`catalog.gd`：Mod；`scene_format.gd`：场景校验；`main.gd`：交互与 UI。

运行 `./Start.ps1 -Test` 执行集成验证，结果在 `test-results/integration.json`，日志在 `runtime.log`。`tools/check_scene.gd` 可单独检查场景文件；`tools/build_example_model.py` 可重新生成原创示例水塔 GLB。

音效专项验证已纳入集成测试，也可用 Godot 参数 `--headless --path . -- --audio-test` 单独运行，结果在 `test-results/audio.json`。`python tools/build_audio.py` 可重新生成 `assets/audio/` 的 15 个音效文件。

运行 Godot 参数 `--path . --script res://tests/audio_output.gd` 可验证实际混音输出、暂停/静音和声音设置窗口的两种尺寸，结果在 `test-results/audio-output.json`，界面截图在 `screenshots/audio-*.png`；此验证需要可用的音频设备与图形显示。

`scripts/steam_locomotive.gd` 生成并缓存蒸汽机车网格；静态细节按材质合并，车轴与连杆按实际行程驱动。蒸汽机车专项验证已纳入集成测试；也可用 Godot 参数 `--headless --path . -- --steam-test` 单独运行，结果在 `test-results/steam-locomotive.json`。去掉 `--headless` 并加 `--steam-capture`，可在 `screenshots/` 生成整车、动轮、驾驶室、烟雾及实际沙盘画面。

`scripts/detailed_vehicles.gd` 负责五种非蒸汽内置车辆和示例山地柴油机车，保留既有尺寸、动力和车辆 ID；旧存档自动使用新外观，自定义 GLB 仍优先加载。模型为原创风格化设计，并非特定实车的测绘复刻。专项检查可用 Godot 参数 `--headless --path . -- --vehicles-test` 运行，覆盖 HO/N 包络、车轮净空、网格完整性、动画、预览、连接与存档；去掉 `--headless` 并加 `--vehicles-capture` 可生成各车近景和 `screenshots/vehicles-detailed-gallery.png` 总览。

柔轨专项验证结果在 `test-results/flex-track.json`，覆盖 HO/N 曲线、自动连接、失败处理、鼠标两次选点、存档/撤销与正反向行车。可直接使用 Godot 参数 `--headless --path . -- --flex-test` 单独运行；去掉 `--headless` 并加 `--flex-capture` 可保存交互画面。

`scripts/vehicle_connections.gd` 根据车辆顺序生成连接件，旧存档无需转换。专项验证使用 `--headless --path . -- --connections-test`，结果在 `test-results/vehicle-connections.json`；去掉 `--headless` 并加 `--connections-capture` 可在 `screenshots/` 生成客车风挡、煤水车牵引杆和货车车钩近景。

碰撞专项验证已纳入集成测试，可用 `--headless --fixed-fps 60 --path . -- --collisions-test` 单独运行，结果在 `test-results/vehicle-collisions.json`。去掉 `--headless` 并加 `--collisions-capture`，可生成道岔并轨与交叉侧撞画面。车辆使用刚性车体，不包含车壳变形、破碎或可断裂车钩。

本版为可运行的功能原型。正常行车采用受轨道约束的纵向模型，轨道尽头脱轨后采用逐车刚体和简化车钩连接。弯道关闭保护后仍沿轨运行，列车之间的正常行车接触仍以保护停车处理；尚未实现轮缘接触、车钩断裂及弹性、空气制动管传播、信号闭塞或自动调度。内置车辆/布景为程序生成模型。
